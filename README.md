🏃 Run Forever

Run Forever — Your fitness journey, simplified.

Run Forever is a modern fitness tracking application designed to help you stay active, monitor your daily progress, and build healthier habits. With a clean, minimal interface and insightful analytics, it makes tracking your fitness journey simple, intuitive, and motivating.

🌐 Live Demo: run-forever.vercel.app

✨ Features
👟 Step Tracking — Monitor your daily steps and stay on top of your activity goals.
📍 Distance Tracking — Track the distance covered while walking or running.
🔥 Calorie Tracking — Keep track of estimated calories burned during your activities.
⏱️ Run Timer — Measure the duration of your workouts with an intuitive timer.
📊 Activity History — Review previous activities through clean, organized cards.
📈 Analytics Dashboard — Explore weekly and monthly fitness trends and performance insights.
🎯 Goal Setting — Set daily fitness targets and track your progress toward achieving them.
🌙 Dark Mode — Enjoy a comfortable viewing experience in light and dark themes.
✨ Smooth Animations — Experience fluid transitions, subtle interactions, and a polished interface.
📱 Responsive Design — Enjoy a consistent experience across supported screen sizes.
🎨 Design Philosophy

Run Forever embraces a minimal, elegant, and user-first design philosophy, inspired by Apple's Human Interface Guidelines.

The interface focuses on clarity, simplicity, and usability to make fitness tracking feel effortless.

Clean layouts with generous whitespace
Soft gradients and subtle shadows
Rounded corners and modern typography
Intuitive navigation and clear visual hierarchy
Smooth transitions and thoughtful micro-interactions
Consistent design across screens
Accessible and easy-to-understand fitness insights

🚀 Getting Started

Follow these steps to set up the project locally.

Prerequisites

Make sure you have the following installed:

Node.js — if required by the project
npm or another package manager compatible with the project
Git
Installation

1. Clone the repository

bash
git clone https://github.com/arjuniverse/RunForever.git


2. Navigate to the project directory

bash
cd RunForever


3. Install dependencies

bash
npm install


4. Start the development server

bash
npm start


If your framework uses a different development command, such as npm run dev, use the script defined in your package.json.

5. Open the application

Follow the local URL displayed in your terminal to access Run Forever in your browser.
